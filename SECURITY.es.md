# Seguridad

[Read in English](SECURITY.md)

segwatch envía paquetes entre redes. Úsalo solo en redes propias o en las
que tengas permiso por escrito para hacer pruebas.

No es un escáner: solo contacta las direcciones y los puertos escritos en la
política, con un límite de velocidad. El respondedor nunca ejecuta comandos;
solo devuelve un mensaje corto que empieza por `SEGW1 `.

Para informar de una vulnerabilidad, abre un aviso de seguridad privado en
GitHub (pestaña Security → "Report a vulnerability"). Por favor, no abras una
issue pública.
